# 全站主题

## 用户设置

房间首页的调色板按钮、房间桌面顶栏、手机菜单和精简模式均提供「自定义主题」。

- 显示模式：浅色、深色、跟随系统，系统外观变化会即时更新。
- 手动配色：8 个预设，支持 HEX 与原生选色器。
- 浅／深色背景、面板色分别保存。极端亮度会校正以保留可读性。
- Monet：Google Material Color Utilities 的 Celebi 量化、Score 评分和 HCT
  CorePalette，从当前封面生成主色和轻微染色的中性背景。
  可与任一显示模式组合；取色失败使用手动种子生成色板。
- 预览不保存；关闭、Escape、取消会恢复最后保存的设置。
- 恢复默认也先预览，需保存才会生效。
- JSON 导入／导出仅包含主题配置，不含账号、房间、封面 URL 或播放信息。
- 设置仅保存在本浏览器；同源标签页同步，不向服务器写入。

## 实现约定

- `src/logic/theme.js`：配置白名单、校验、配色生成和 WCAG 对比度工具。
- `src/logic/themeRuntime.js`：一次性运行时，统一设置 CSS 变量、系统监听、
  浏览器 UI theme-color、持久化与标签页同步。
- `src/stores/appearance.js`：设置面板会话；`stores/ui.js` 兼容原来的明暗切换。
- `src/logic/monet.js`：可取消的匿名 CORS 取色，32×32 像素采样、4 秒超时。
  量化代码延迟加载。无图片代理、上传或后台接口。
- `index.html`：同步恢复由运行时派生的双模式缓存，避免刷新时先闪默认主题；
  缓存必须与当前配置完全匹配且 RGB 数值合法，否则忽略。
- `mp_appearance_v1` 为唯一持久配置，旧 `mp_theme` 首次保存时迁移。
  `mp_appearance_boot_v1` 只是可丢弃的首屏派生缓存。
- 核心文字、强调文字、按钮前景和悬停状态自动达到至少 4.5:1 的目标对比度；
  错误／成功／警告保留语义色相并适配表面亮度。
- DOM 使用语义 CSS 变量，Canvas 使用 `getVisualTheme()`；不要写死品牌 RGB。
  点光源精灵仅在颜色改变时重建，半径、柔光曲线、亮度响应和音频图均不受主题控制。

## 边界

- 跨域图片未提供 CORS 许可时无法安全读像素，正常回退，不绕过源站策略。
- 不跟随账号跨设备同步，也不改变其他房间用户的主题。
- 浏览器禁用存储时预览可用，但显示无法保存的提示。
- 需要支持原生 `<dialog>` 的现代浏览器（含 Safari 15.4+）。

测试命令见 `tests/README.md`。
